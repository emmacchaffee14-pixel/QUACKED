# .quacked/

Quacked's internal AI operating system — the canonical source of truth for how this codebase works, replacing ad-hoc knowledge scattered across chat history and the (now-frozen) Backend Architecture Handbook v3.4.

## Structure

- `workflows/` — step-by-step playbooks for recurring engineering tasks (e.g. adding a new archetype batch). Update these when a workflow surfaces a new gotcha — don't let them go stale.
- `knowledge/` — reference docs on how specific systems work (tech stack, schema conventions, etc.) — planned, not yet populated.
- `agents/` — role-specific instructions for AI agents working in this repo — planned, not yet populated.
- `templates/` — reusable scaffolding for common file types — planned, not yet populated.
- `decisions/` — record of significant architecture/product decisions and why they were made — planned, not yet populated.
- `scratchpad/` — temporary working files, not meant to be durable.
